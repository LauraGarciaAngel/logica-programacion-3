# Práctica de Lógica de Programación: Factorial (logica-programacion-3)

Programa en **JavaScript** que calcula el factorial de un número entero positivo ingresado por el usuario.

## 📋 Requisitos cumplidos
- Solicita el número al usuario mediante `prompt`.
- Valida que la entrada sea estrictamente un número entero mayor o igual a 0 (rechaza textos, decimales, números negativos y entradas vacías).
- Si la entrada no es válida, notifica el error y vuelve a solicitar el dato.
- Calcula el factorial mediante un ciclo iterativo.
- Muestra el resultado tanto en la consola (`console.log`) como en el documento HTML (`DOM`).

## 🚀 Cómo ejecutarlo
1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador favorito (haciendo doble clic o con la extensión Live Server de VS Code).
3. Ingresa un número cuando te lo solicite y observa el resultado.

## 🧪 Ejemplos de prueba
- `0!` = 1
- `4!` = 24
- `5!` = 120
- `6!` = 720
